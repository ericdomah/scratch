## 1. Single Source of Truth (SSoT) Metrics
These are the final, mathematically verified performance metrics achieved by the Triple-Hybrid Meta-Ensemble after 10-fold Stratified Cross-Validation:

*   **F1-Score:** 0.905 (90.5%)
*   **Precision (Theft Detection):** 91.13% (often rounded to 91.1%)
*   **Recall (False Negative Suppression):** 89.81% (often rounded to 89.8%)
*   **Accuracy:** 98.23%
*   **AUROC (Area Under ROC):** 0.952

## 2. Dataset & Experimental Setup
The data engineering phase utilized a physics-grounded simulation (Digital Twin / TheftInjector) to overcome the flaws of standard mathematical oversampling (like SMOTE).

*   **Total Telemetry Packets:** 1,200,000
*   **Smart Meters Modeled:** 1,500 (representing KIB-TEK TRNC districts)
*   **Total Dataset Samples (Tensors):** 25,863 smart meter samples
*   **Class Balance (Prevalence):** 
    *   Normal Operation: 85.00%
    *   Theft / Anomalies: 15.00%
*   **Time Sequence Window:** 26-weeks (12 months of simulated consumption at 15-minute intervals)

### Key Feature Engineering (SHAP Significance)
| Feature Category | Description | Significance (SHAP) |
| :--- | :--- | :--- |
| **Temporal Delta** | 24h consumption variance | High |
| **Phase Symmetry** | Voltage/Current unbalance across 3-phase lines | Very High |
| **Forensic Shift** | Significant drop in night-time baseline | Critical |
| **Transformer Loss** | Delta between substation output and consumer sum | System-Level |

## 3. Latency & Infrastructure Benchmarks
To prove real-world operational viability, the system was benchmarked against the 15 ms real-time utility streaming constraint:

*   **Tier 1 (Edge Node - XGBoost):** 1.02 ms inference latency. Acts as a gatekeeper, filtering out 99% of normal traffic locally.
*   **Tier 2 (Cloud Node - Deep Learning Hybrid):** 6.225 ms mean latency. Computes the heavy sequential forensics.
*   **Total System Inference Latency (Meta-Ensemble):** 12.25 ms per inference (safely below the 15 ms constraint).

---

## 4. Individual Model Comparison (Edge vs. Cloud)
GridGuard AI splits the workload between two distinct models in a Two-Tier Cascade Architecture:

| Feature | Tier 1: Edge Node (XGBoost) | Tier 2: Cloud Node (Super-Hybrid DL) |
| :--- | :--- | :--- |
| **Primary Role** | High-speed, first-pass filter for normal traffic | Deep forensic analysis for suspected theft |
| **Architecture Type** | Gradient Boosted Decision Trees | TCN + Bi-LSTM + Transformer Encoder |
| **Deployment Location** | Edge Substation / Local Gateway | Centralized Cloud Server / K8s Cluster |
| **Data Perspective** | Tabular / Statistical Aggregations | Pure 1D Sequential Time-Series |
| **Inference Latency** | **Extremely Fast** (1.02 ms) | **Heavier** (6.225 ms) |
| **Precision Strategy** | Precision-Maximized (Only flags obvious anomalies) | Recall-Maximized (Catches hidden/complex theft) |

## 5. Comparative Analysis vs. SOTA Literature (2022–2024)
GridGuard AI was benchmarked against standard baselines to highlight its novelties:

| Evaluation Criteria | Typical SOTA Literature | GridGuard AI Proposed Methodology | Impact / Advantage |
| :--- | :--- | :--- | :--- |
| **Model Architecture** | Single Model (e.g., standard CNN or Vanilla LSTM). | **Triple-Hybrid Meta-Ensemble** | Fuses local anomalies, historical trends, and global periodicities. |
| **Contextual Awareness**| Single-dimension isolated load profile | **Grid-Aware Context Integration** (GLI) | Drastically reduces false alarms by correlating user drops with substation demand. (Improved precision from ~8% baseline to 91.1%). |
| **Data Augmentation** | Mathematical oversampling (SMOTE) | **Digital Twin Simulation** (TheftInjector) | Models physical hardware tampering rather than random Euclidean noise. |
| **Explainability (XAI)** | Black Box output | **1D Time-Series Integrated Gradients** | Generates Temporal "Suspicion Heatmaps" for forensic justification. |
| **Deployment** | Static Jupyter Notebooks | **Production Ecosystem** (Edge-to-Cloud, K8s) | Proven utility-grade infrastructure scalability. |

*Note: Standard industrial edge baselines (standalone XGBoost) achieve F1-scores of only ~0.854. The Hybrid Meta-Ensemble achieves 0.905.*
